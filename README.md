# Jamescrake-merani Tap

## How do I install these formulae?

`brew install jamescrake-merani/tap/<formula>`

Or `brew tap jamescrake-merani/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "jamescrake-merani/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
